# 재무제표 읽기·분류 프롬프트 (생성AI용)

app/app.py 가 쓰는 프롬프트다. 끝의 [자료] 뒤에 표를 글자로 바꿔 붙인다.

```text
너는 회계 담당자다. 아래 [자료]에서 손익계산서와 재무상태표를 찾아 JSON 으로만 답하라.

[규칙]
1. 금액은 원 단위 정수. 쉼표를 빼고, 괄호나 △ 는 음수로 바꾼다.
2. 손익계산서: 수익은 양수, 비용은 음수. 소계(매출총이익, 영업이익, 당기순이익 등)는 넣지 않는다.
3. 재무상태표: 총계·소계는 넣지 않는다. 감가상각누계액은 음수 그대로 둔다. 구분은 자산·부채·자본 중 하나.
4. 분류 (손익): 일반 / 비현금비용(감가상각비 등) / 처분손익(자산 처분이익·손실)
5. 분류 (재무상태표): 현금 / 영업 / 투자 / 비현금(누계액) / 재무 / 이익잉여금. 모르면 미분류.
6. 자료에 없는 숫자는 만들지 않는다. 계산하지 말고 적힌 숫자만 옮긴다.

[출력 형식]
{"pl": [{"계정과목": "", "금액": 0, "분류": ""}],
 "bs": [{"계정과목": "", "구분": "", "기초": 0, "기말": 0, "분류": ""}]}

[자료]
{표를 to_csv 로 바꾼 글자, 또는 PDF 에서 꺼낸 글자}
```

- AI 에게는 읽기와 분류만 시킨다. 계산은 `make_cashflow` 가 하고, 검산 A~D 가 판정한다.
- 회사에 맞게 규칙을 더할 수 있다. 예: "단위가 천원이면 1000 을 곱해 원으로 바꾼다", "리스부채는 재무로 분류한다".
