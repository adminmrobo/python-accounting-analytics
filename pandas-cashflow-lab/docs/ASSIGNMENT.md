# 과제 안내: 실제 회사의 현금흐름표 자동 작성

실제 회사 한 곳의 재무제표를 앱에 넣어 간접법 현금흐름표를 만들고, 공시된 현금흐름표와 대조해 차이를 설명합니다. 마감일, 제출 방법, 최종 배점은 수업 공지를 따릅니다.

## 무엇을 하는가

- **회사 고르기.** DART(dart.fss.or.kr)에서 회사 한 곳과 회계연도를 정한다. 별도재무제표, 금융업이 아닌 회사, 계정 수가 적은 회사가 좋다.
- **파일 받기.** 감사보고서나 사업보고서에서 재무상태표(당기말·전기말)와 손익계산서가 든 PDF 또는 엑셀을 받는다. 단위(원·천원·백만원)를 적어 둔다.
- **앱 실행.** 규칙 사전 방법과 생성AI 방법으로 각각 읽어 본다. 두 방법이 어디서 다르게 읽었는지 기록한다.
- **검토와 수정.** 정리된 표에서 숫자와 분류를 고쳐 검산 A~D 를 통과시킨다. 필요하면 낱말 사전, 프롬프트, 함수를 고친다. 고친 내용을 남긴다.
- **공시와 대조.** 같은 보고서의 현금흐름표와 활동별 합계를 비교하는 표를 만든다(대조표 카드(#hw_compare)). 차이마다 원인을 주석에서 찾아 적는다.
- **보고서 쓰기.** 아래 제출물을 한 파일(PDF)로 묶고, 결과 엑셀과 코드를 함께 낸다.

## 제출물과 배점 (기본안)

| 제출물 | 담을 내용 | 배점 |
|---|---|---|
| 앱 실행 화면 | 원본 표, 정리된 표, 현금흐름표, 검산표가 보이는 화면. 회사 이름과 회계연도를 함께 적는다 | 20 |
| 결과 엑셀 | 앱에서 내려받은 cashflow.xlsx (현금흐름표, 검산, 정리된 손익계산서·재무상태표 시트) | 15 |
| 공시 대조표 | 활동별로 앱 · 공시 · 차이 · 원인. 차이의 합이 0 인지, 아니라면 왜인지 | 30 |
| AI 분류 검토표 | 생성AI 와 사전이 다르게 분류한 계정, 내가 고른 분류와 근거. 사용한 프롬프트와 AI 의 답 원문을 부록으로 | 20 |
| 코드 수정 내역 | 낱말 사전에 더한 낱말, 프롬프트에 더한 규칙, 고친 함수와 그 이유 | 15 |
| **합계** | | 100 |

숫자가 공시와 정확히 같아야 만점인 과제가 아닙니다. 주석 없이 재무상태표와 손익계산서만으로 만든 현금흐름표는 공시와 다를 수 있고, 그 차이를 찾아 설명하는 것이 평가의 중심입니다.

## 지킬 것

- API 키를 코드, 보고서, 화면 캡처, 깃허브에 남기지 않는다.
- 생성AI 를 쓴 곳(표 읽기, 분류, 코드 수정 도움)을 보고서에 밝힌다. AI 의 답을 고치지 않고 그대로 낸 부분과 직접 고친 부분을 구분한다.
- 검산을 통과시키려고 숫자를 임의로 맞추지 않는다. 통과하지 못한 검산은 그대로 두고 원인을 적는다.
- 공시 자료의 출처(회사, 보고서 이름, 공시일)를 적는다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| 검산 A (대차) 실패 | 숫자를 잘못 읽었거나 총계·소계 줄이 남았다. 괄호 음수, 단위, `SUBTOTAL` 목록을 확인한다 (to_num(#to_num), ffill(#ffill_head)) |
| 검산 B (미분류) 실패 | 사전에 없는 계정이다. `RULE_BS` 에 낱말을 더하거나 화면에서 분류를 고른다 (by_rule(#by_rule)) |
| 검산 D 와 C 가 같은 금액만큼 실패 | 유형자산 처분, 무형자산 상각, 대손·퇴직급여 같은 비현금 항목이 있다. 손익계산서에서 해당 비용의 분류를 '비현금비용' 으로 바꾸거나 주석을 본다 (engine(#engine)) |
| PDF 에서 표가 안 나온다 | 표에 선이 없거나 스캔본이다. 생성AI 방법으로 읽거나 엑셀 파일을 받는다 (pdf_tables(#pdf_tables)) |
| AI 의 답이 표로 안 바뀐다 | JSON 이 아닌 글이 섞였거나 열이 빠졌다. 답 원문을 열어 보고 다시 부른다 (json_parse(#json_parse)) |
| 공시와 활동별 숫자가 다르다 | 정상이다. 이자·배당·법인세의 분류, 총액과 순액, 비현금거래를 주석에서 찾는다 (hw_compare(#hw_compare)) |

---
괄호 안의 #이름 은 책의 카드 주소다 (예: `.../#hw_compare`). 배점은 기본안이며 수업 공지가 우선한다.
