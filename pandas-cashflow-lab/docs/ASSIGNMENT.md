# 과제 안내: 내 회사의 현금흐름표와 분석보고서

내 학번으로 만든 회사의 현금흐름표·재무비율·차트를 Colab 으로 만들고, 정해진 프롬프트로 생성AI 분석보고서를 받아 검산하고 고쳐서 냅니다. 마감일, 제출 방법, 최종 배점은 수업 공지를 따릅니다.

## 무엇을 하는가

- **CSV 받기.** 생성기에 내 학번을 넣고 `재무제표_학번.csv` 와 확인 코드를 받는다.
- **Colab 실행.** 한 셀로 끝내기(#all_in_one)(또는 실습 노트북의 5~10장 셀)를 실행해 결과 파일 다섯 개를 받는다: 현금흐름표·재무비율 CSV, 차트 PNG, 보고서 프롬프트 txt, 보고서 검증표 CSV.
- **엑셀로 대조.** `data/내회사_엑셀검산.xlsx` 의 '재무제표' 시트에 내 CSV 를 붙여 넣고, 현금흐름표 합계와 재무비율이 Colab 결과와 같은지 본다.
- **생성AI 보고서.** 보고서 프롬프트를 **고치지 않고** 생성AI 에 붙여 넣는다. 받은 보고서 원문을 저장한다.
- **검산과 수정.** 검증표의 '보고서의 숫자' 와 'O/X' 를 채운다. 틀린 숫자, 자료에 없는 숫자를 고치고 고친 곳을 표시한다.
- **내 의견.** AI 보고서에 없는 내 해석 한 단락을 쓴다. 특히 이익과 현금이 다른 이유를 내 회사의 숫자로 설명한다.
- **제출.** 보고서 첫 줄에 회사명 · 학번 · 확인 코드를 적고, 아래 제출물을 하나의 PDF 와 파일 묶음으로 낸다.

## 제출물과 배점 (기본안)

| 제출물 | 담을 내용 | 배점 |
|---|---|---|
| Colab 실행 화면 | 현금흐름표, 검산 통과(True), 재무비율 표가 보이는 화면 | 20 |
| 결과 파일 | 현금흐름표_학번.csv, 재무비율_학번.csv, 차트_학번.png | 15 |
| 생성AI 분석보고서 | 고친 최종본. 생성AI 원문은 부록으로. 사용한 생성AI 이름과 날짜 | 25 |
| 보고서 검증표와 고친 곳 | 보고서검증_학번.csv 를 채운 것, 틀린 숫자와 지어낸 숫자를 어떻게 고쳤는지 | 25 |
| 내 의견 | AI 보고서에 없는 해석 한 단락, 프롬프트를 어떻게 바꾸면 좋을지 | 15 |
| **합계** | | 100 |

학번마다 숫자가 달라 남의 보고서를 그대로 쓸 수 없습니다. 교수자는 같은 학번으로 생성기를 열어 숫자와 확인 코드를 대조합니다. 생성AI 가 쓴 문장을 그대로 낸 부분과 직접 고친 부분이 구분되어야 합니다.

## 지킬 것

- 내 학번으로 받은 CSV 만 쓴다. 생성기 숫자를 엑셀에서 고치지 않는다.
- 정해진 프롬프트를 고치지 않고 쓴다. 바꾸고 싶은 점은 '내 의견' 에 적는다.
- 판정의 기준은 교육용 참고값이다. 보고서에 '업종 평균' 이라고 쓰지 않는다.
- 검산을 통과시키려고 숫자를 임의로 맞추지 않는다. 통과하지 못하면 원인을 적는다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| `IndexError: list index out of range` | '파일 선택' 에서 파일을 고르지 않고 취소했다. 셀을 다시 실행하고 CSV 를 고른다 (upload(#upload)) |
| `NameError: name 'bs' is not defined` | 앞 셀을 실행하지 않았다. 5장 upload 부터 차례로 실행하거나 한 셀로 끝내기를 쓴다 |
| `KeyError: '회사명'` 등 | CSV 를 엑셀에서 고쳐 저장하면서 열 이름이 바뀌었다. 생성기에서 다시 받는다 |
| 파일 이름이 `재무제표_학번 (1).csv` | 같은 파일을 두 번 올렸다. Colab 왼쪽 폴더에서 옛 파일을 지우고 다시 올린다 |
| 내려받기가 안 된다 | 브라우저가 여러 파일 내려받기를 막았다. 주소창의 차단 아이콘에서 허용하거나 왼쪽 폴더에서 ⋮ → 다운로드 (save_csv(#save_csv)) |
| 차트 글자가 네모(□) | 차트에 한글을 넣었다. 이 책의 차트는 영어로 적는다. 꼭 한글을 쓰려면 카드 위의 '차트 한글 표시 안내' 를 본다 |
| 보고서 숫자가 정답표와 다르다 | 생성AI 가 잘못 옮겼거나 지어낸 것이다. 정답표의 숫자로 고치고 고친 곳을 표시한다 (ai_verify(#ai_verify)) |

괄호 안의 #이름 은 책의 카드 주소다 (예: `.../#hw_compare`). 배점은 기본안이며 수업 공지가 우선한다.
