저녁 일곱 시, 재무제표 두 장이 도착했다
"이익 170 은 어떻게 현금 270 이 될까?"

손익계산서와 재무상태표만 있으면 현금흐름표를 만들 수 있습니다. 이 책은 그 과정을 pandas 명령어 한 줄씩으로 나눠 표가 한 단계씩 움직이는 그림으로 보여 줍니다. 손으로 한 번 만들어 본 뒤에는 엑셀·PDF 파일을 읽고, 생성AI 에게 표 읽기와 계정 분류를 맡기고, 검산까지 하는 앱으로 만듭니다. 마지막 장은 실제 회사에 적용하는 과제 안내입니다.

LOG 19:00 장부 상담소

봉투에서 재무제표 두 장을 꺼낸 직후의 기록입니다.

[SYSTEM] 서류 2장 접수. 손익계산서 1장, 재무상태표(기초·기말) 1장. 요청: "현금흐름표를 간접법으로 만들어 주세요. 다음 달부터는 파일만 올리면 되게 해 주세요."
조수이익은 170 인데 현금은 150 늘었대요. 숫자가 왜 달라요? 그리고 이걸 매달 손으로 해요?
박사먼저 손으로 한 번 해 봐요. 이익에서 출발해 다섯 계단을 오르면 영업현금이에요. 원리를 알고 나면 파일을 올리는 앱으로 바꿔요.
초파리 연구원AI 한테 시키더라도 계산은 pandas 가 하고, 맞는지는 검산이 정해. 세 활동을 더해서 현금 증감이랑 안 맞으면 틀린 거야.
주판봇삐빅, 계산 중… __CARD_COUNT__장 모두 실제로 돌려 본 결과를 실었어. 영업 270, 투자 −500, 재무 380.

질문
손익계산서와 재무상태표에서 현금흐름표는 어떻게 나오는가? 그 일을 파일만 올리면 되게 만들 수 있는가?
방법
0~4장은 숫자를 코드에 적고 간접법을 한 줄씩 만든다. 5~7장은 엑셀·PDF 를 읽고 생성AI 와 검산을 붙여 앱으로 만든다.
원칙
생성AI 는 표를 읽고 계정을 분류한다. 계산은 pandas 가 한다. 맞는지는 검산이 판정하고, 사람이 고칠 수 있는 칸을 둔다.
확인
코드는 Colab 새 셀에 붙여 넣으면 파일 없이 돈다. 오른쪽 실행 결과와 똑같이 나오는지 맞춰 본다.
권장 순서
0장 → 8장. 과제를 하는 학생은 앱 만드는 순서와 과제 안내를 먼저 읽는다

APP 앱을 만드는 일곱 걸음

엑셀이나 PDF 를 올리면 현금흐름표가 나오는 앱을 처음부터 끝까지 만드는 순서입니다. 걸음마다 해당 카드로 가는 링크가 있습니다.

  1. 준비물을 갖춘다

    구글 계정 하나면 시작할 수 있다. Colab(colab.research.google.com)에서 코드를 실행하고, Google AI Studio(aistudio.google.com)에서 생성AI 의 API 키를 받는다. 앱을 인터넷에 올리려면 깃허브 계정이 더 필요하다. 내 PC 에서 띄우려면 파이썬을 설치한다.

  2. 손으로 한 번 만든다 (0~4장)

    0장에서 전체 그림을 보고, 1장에서 재무제표를 표로 담고, 2장의 다섯 계단으로 영업현금 270 을, 3장에서 투자 −500 과 재무 380 을 만든다. 4장의 검산(세 활동의 합 = 현금 증감 150)이 통과하면 원리는 끝이다. 앱은 이 계산을 그대로 옮긴 것이다.

  3. 파일에서 숫자를 꺼낸다 (5장)

    read_excel 로 엑셀을, pdfplumber 로 PDF 의 표를 읽는다. 공시의 표는 지저분하다. 이름 정리, 숫자 변환, 구분 채우기, 소계 제거와 부호, 낱말 사전 분류를 함수로 만든다. 여기까지가 '규칙 사전' 방법이다.

  4. API 키를 발급받는다

    AI Studio 에 구글 계정으로 로그인하고 API 키 메뉴에서 새 키를 만들어 복사한다. 키는 비밀번호와 같다. 코드나 보고서, 깃허브에 적지 않는다(키 보관). 키가 없어도 6장은 저장된 예시 응답으로 끝까지 연습할 수 있다. 모델 이름과 무료 사용 한도는 자주 바뀌므로 AI Studio 화면에서 확인한다.

  5. 생성AI 에게 읽기와 분류를 맡긴다 (6장)

    프롬프트는 규칙 · 출력 형식(JSON) · 자료 세 부분이다. ask_ai 로 부르고, JSON 을 표로 바꾸고, 세 가지 검사로 답을 걸러 낸다. 사전의 분류와 비교해 다른 줄만 사람이 본다.

  6. 앱으로 묶어 띄운다 (7장)

    make_cashflow 가 계산과 검산을 한 번에 한다. app.py 는 파일 올리기 → 표 정리 → 사람 검토 → 계산 → 검산 → 내려받기를 한 화면에 잇는다. 세 가지 방법 중 하나로 띄우고 '연습 자료로 해 보기' 를 켜서 270, −500, 380, 150 이 나오는지 본다. 저장소의 app/app.py, data/sg_2014.xlsx, data/sg_2014.pdf 를 그대로 써도 된다.

  7. 실제 회사 파일을 올린다 (8장)

    실제 공시는 연습 파일보다 계정이 많고 이름이 다르다. 규칙 사전은 대개 미분류를 남긴다. 사전에 낱말을 더하거나, 생성AI 방법으로 읽거나, 화면의 표에서 직접 고친다. 검산 A~D 를 통과시킨 뒤 공시와 대조한다. 여기서부터가 과제다.

HOMEWORK 과제 안내

실제 회사 한 곳의 재무제표를 앱에 넣어 간접법 현금흐름표를 만들고, 공시된 현금흐름표와 대조해 차이를 설명합니다. 마감일, 제출 방법, 최종 배점은 수업 공지를 따릅니다.

■ 무엇을 하는가

  1. 회사 고르기. DART(dart.fss.or.kr)에서 회사 한 곳과 회계연도를 정한다. 별도재무제표, 금융업이 아닌 회사, 계정 수가 적은 회사가 좋다.
  2. 파일 받기. 감사보고서나 사업보고서에서 재무상태표(당기말·전기말)와 손익계산서가 든 PDF 또는 엑셀을 받는다. 단위(원·천원·백만원)를 적어 둔다.
  3. 앱 실행. 규칙 사전 방법과 생성AI 방법으로 각각 읽어 본다. 두 방법이 어디서 다르게 읽었는지 기록한다.
  4. 검토와 수정. 정리된 표에서 숫자와 분류를 고쳐 검산 A~D 를 통과시킨다. 필요하면 낱말 사전, 프롬프트, 함수를 고친다. 고친 내용을 남긴다.
  5. 공시와 대조. 같은 보고서의 현금흐름표와 활동별 합계를 비교하는 표를 만든다(대조표 카드). 차이마다 원인을 주석에서 찾아 적는다.
  6. 보고서 쓰기. 아래 제출물을 한 파일(PDF)로 묶고, 결과 엑셀과 코드를 함께 낸다.

숫자가 공시와 정확히 같아야 만점인 과제가 아닙니다. 주석 없이 재무상태표와 손익계산서만으로 만든 현금흐름표는 공시와 다를 수 있고, 그 차이를 찾아 설명하는 것이 평가의 중심입니다.

■ 지킬 것

  • API 키를 코드, 보고서, 화면 캡처, 깃허브에 남기지 않는다.
  • 생성AI 를 쓴 곳(표 읽기, 분류, 코드 수정 도움)을 보고서에 밝힌다. AI 의 답을 고치지 않고 그대로 낸 부분과 직접 고친 부분을 구분한다.
  • 검산을 통과시키려고 숫자를 임의로 맞추지 않는다. 통과하지 못한 검산은 그대로 두고 원인을 적는다.
  • 공시 자료의 출처(회사, 보고서 이름, 공시일)를 적는다.

■ 자주 막히는 곳

증상원인과 해결
검산 A (대차) 실패숫자를 잘못 읽었거나 총계·소계 줄이 남았다. 괄호 음수, 단위, SUBTOTAL 목록을 확인한다 (to_num, ffill)
검산 B (미분류) 실패사전에 없는 계정이다. RULE_BS 에 낱말을 더하거나 화면에서 분류를 고른다 (by_rule)
검산 D 와 C 가 같은 금액만큼 실패유형자산 처분, 무형자산 상각, 대손·퇴직급여 같은 비현금 항목이 있다. 손익계산서에서 해당 비용의 분류를 '비현금비용' 으로 바꾸거나 주석을 본다 (engine)
PDF 에서 표가 안 나온다표에 선이 없거나 스캔본이다. 생성AI 방법으로 읽거나 엑셀 파일을 받는다 (pdf_tables)
AI 의 답이 표로 안 바뀐다JSON 이 아닌 글이 섞였거나 열이 빠졌다. 답 원문을 열어 보고 다시 부른다 (json_parse)
공시와 활동별 숫자가 다르다정상이다. 이자·배당·법인세의 분류, 총액과 순액, 비현금거래를 주석에서 찾는다 (hw_compare)
