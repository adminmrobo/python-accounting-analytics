FLOW 실습 여섯 걸음

학번 하나로 시작해 분석보고서까지 가는 순서입니다. 걸음마다 해당 카드로 가는 링크가 있습니다.

  1. 간접법을 손으로 익힌다 (0~4장)

    0장에서 전체 그림을 보고, 1장에서 재무제표를 표로 담고, 2장의 다섯 계단으로 영업현금을, 3장에서 투자·재무활동을 만든다. 4장의 검산(세 활동의 합 = 현금 증감)이 통과하면 원리는 끝이다.

  2. 학번으로 내 회사 CSV 를 받는다

    재무제표 생성기에 내 학번을 넣으면 가상 회사의 재무상태표(기초·기말)와 손익계산서가 만들어진다. 'CSV 내려받기' 로 재무제표_학번.csv 를 받고, 화면의 확인 코드를 적어 둔다. 같은 학번은 언제나 같은 숫자다. 표본은 학번 20261005.

  3. Colab 에 올려 읽는다 (5장)

    실습 노트북을 Colab 에서 열거나 새 노트북을 만든다. upload 카드의 코드를 붙여 넣고 실행하면 '파일 선택' 단추가 나온다. CSV 를 고르면 재무상태표와 손익계산서로 나누고, 대차와 '이익 vs 현금'을 확인한다.

  4. 현금흐름표 · 차트 · 재무비율을 만든다 (6~8장)

    내 회사의 현금흐름표와 이익과 현금이 다른 이유 세 가지, 차트 세 장, 재무비율 열세 개와 양호·주의 판정이 나온다. 한 번에 하려면 한 셀로 끝내기를 붙여 넣는다.

  5. CSV 와 그림으로 저장한다 (9장)

    현금흐름표_학번.csv · 재무비율_학번.csv와 차트_학번.png가 내려받아진다. 엑셀로 열어도 한글이 깨지지 않는다. data/내회사_엑셀검산.xlsx 에 내 CSV 를 붙여 넣으면 같은 숫자가 엑셀 수식으로도 나온다.

  6. 생성AI 로 분석보고서를 완성한다 (10장)

    ai_prompt 카드가 정해진 프롬프트에 내 숫자를 붙여 한 덩어리로 출력한다. 그 글을 고치지 않고 생성AI 채팅창(ChatGPT, Claude, Gemini 등)에 붙여 넣으면 보고서가 나온다. 보고서검증_학번.csv로 숫자를 맞춰 보고 고친다. 여기서부터가 과제다.

내 학번으로 만든 회사의 현금흐름표·재무비율·차트를 Colab 으로 만들고, 정해진 프롬프트로 생성AI 분석보고서를 받아 검산하고 고쳐서 냅니다. 마감일, 제출 방법, 최종 배점은 수업 공지를 따릅니다.

■ 무엇을 하는가

  1. CSV 받기. 생성기에 내 학번을 넣고 재무제표_학번.csv 와 확인 코드를 받는다.
  2. Colab 실행. 한 셀로 끝내기(또는 실습 노트북의 5~10장 셀)를 실행해 결과 파일 다섯 개를 받는다: 현금흐름표·재무비율 CSV, 차트 PNG, 보고서 프롬프트 txt, 보고서 검증표 CSV.
  3. 엑셀로 대조. data/내회사_엑셀검산.xlsx 의 '재무제표' 시트에 내 CSV 를 붙여 넣고, 현금흐름표 합계와 재무비율이 Colab 결과와 같은지 본다.
  4. 생성AI 보고서. 보고서 프롬프트를 고치지 않고 생성AI 에 붙여 넣는다. 받은 보고서 원문을 저장한다.
  5. 검산과 수정. 검증표의 '보고서의 숫자' 와 'O/X' 를 채운다. 틀린 숫자, 자료에 없는 숫자를 고치고 고친 곳을 표시한다.
  6. 내 의견. AI 보고서에 없는 내 해석 한 단락을 쓴다. 특히 이익과 현금이 다른 이유를 내 회사의 숫자로 설명한다.
  7. 제출. 보고서 첫 줄에 회사명 · 학번 · 확인 코드를 적고, 아래 제출물을 하나의 PDF 와 파일 묶음으로 낸다.

차트 한글 표시 안내: 로컬 파이썬에서는 한글이 보이지만, Colab 에서는 글꼴 문제로 한글이 네모(□)로 깨질 수 있다

Colab 의 기본 글꼴(DejaVu Sans)에는 한글이 없다. 그래서 이 페이지의 예제는 차트 제목·축·범례를 영어로 적었다. 표(DataFrame) 출력과 print 의 한글은 Colab 에서도 깨지지 않는다.

Colab 차트에 꼭 한글을 써야 하면 아래 셀을 한 번 먼저 실행한다.

# Colab: 나눔고딕 설치 후 차트 글꼴로 지정
!apt-get -qq install fonts-nanum > /dev/null
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
fm.fontManager.addfont("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")
plt.rcParams["font.family"] = "NanumGothic"
plt.rcParams["axes.unicode_minus"] = False   # 마이너스 기호 깨짐 방지

로컬 파이썬(내 PC 의 Jupyter, VS Code 등)은 PC 에 한글 글꼴이 깔려 있어 한글 차트를 그릴 수 있다. 단 matplotlib 기본값도 DejaVu Sans 이므로, 처음 한 번은 아래처럼 한글 글꼴을 지정해 둔다.

plt.rcParams["font.family"] = "Malgun Gothic"   # Windows (맥은 "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False
