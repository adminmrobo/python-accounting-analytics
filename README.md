## 각 주차 페이지의 구조 (비전공자판)

3D 본사 타워 → 표지 → 히어로 → 처음 오신 분께(3줄) → 연구실 식구 → 왜 이 주제인가 → 칸 ①②③ → 한눈에 보는 대시보드 → 대결 → 정리 → 아웃트로 → 지식 색인 → 온톨로지·서지 꾸러미 → 바닥글.

칸마다: 가져갈 한 가지 · 왜 이 방법을 쓰나 · 수식을 어려워하는 조수가 대신 묻는 상자(학교 수학 단원 → 식 조각 → 숫자로 해 보기) · 일상으로 치면 | 회계로는 · 칸 대화 · 실험 · 풀이와 이 칸의 한계 · 접어 둔 파이썬 코드 · 확인 퀴즈 2문항.

각 페이지는 한 파일이며 외부 파일 없이 열립니다(글꼴은 Google Fonts, 3D는 three.js CDN).

## 데이터와 정확성

- 카페 코이와 예제 회사의 숫자는 모두 **설명용 예시값**이며 실제 기업 자료가 아닙니다. 교육용이며 회계·세무·투자 자문이 아닙니다.
- 숫자는 모두 다시 계산했고, 원자료와 다른 곳은 각 페이지 바닥글의 **「원자료와 다르게 쓴 곳」**에 적었습니다.

| 주차 | 원자료 | 이 시리즈 |
|---|---|---|
| 3 | 광고비 선급 300만 원 중 「100만 원 비용화」와 「300만 원 / 6개월」이 함께 나옴 | 6개월 균등(월 50만 원)으로 통일 |
| 4 | 실습 자료(workshop-koi-4q.csv)의 법인세 176만 원(세전이익 800만 원 가정) | 같은 자료의 분개로 계산한 세전이익 380만 원 × 22% = 83.6만 원 |

| 8 | 후입선출법 기말재고 8,000 · 매출원가 10,500 · 매출총이익 23,400 − 10,500 = 12,900 | 7,200 · 10,300 · 21,000 − 10,300 = 10,700 |

| 8 | 「7년차까지 보면 정액·정률 합계가 비슷」 | 정액법 3,000만 원, 정률법 20% 약 2,370.9만 원 |
